# AI Leadership & Learning Innovation Landing Page

This is a single-file GitHub Pages landing page designed to serve as the executive-facing front door to Kristin Bartholomew's AI and learning innovation work.

## Files
- `index.html` — complete responsive landing page.
- Add a PDF resume named `Kristin_Bartholomew_Resume.pdf` to the same folder if you want the resume button to work as written.

## Publish with GitHub Pages
1. Create a new repository or place `index.html` in the root of an existing GitHub Pages repository.
2. Add the resume PDF if desired.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing `index.html` and the root folder.
6. Save.
